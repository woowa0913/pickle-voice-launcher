# 🥒 피클 보이스 (Pickle Voice Launcher)

LG K-EXAONE 2.5(후후)가 직접 작성한 초경량 안드로이드 음성 통화 런처 앱입니다.

## 기능
- 실행 즉시 화면 깜빡임 없이 피클 앱의 실시간 음성 통화(`pickle://call`)를 호출하고 스스로 즉시 종료(`finish()`)합니다.
- 용량: 빌드 시 100KB 미만 초경량

## 사용 방법
1. 안드로이드 스튜디오에서 본 폴더를 열고 **Build > Build Bundle(s) / APK(s) > Build APK(s)** 실행
2. 스마트폰에 설치
3. 갤럭시 **[설정] > [유용한 기능] > [측면 버튼] > [두 번 누르기]**에 **'피클 보이스'** 지정!
   - 주머니에서 전원 버튼 두 번 딸깍 누르면 0.1초 만에 피클 실시간 음성 통화 연결!
